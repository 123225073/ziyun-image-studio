# 0.3.0 任务排序与批量混剪

## 图片任务

在任务表中拖动整行即可上下换位置，左侧拖动标记也可使用。编号由用户维护，例如 A01、A02、B01；拖动不会重编编号，也不会改变参考图、提示词、生成参数、已有结果和历史任务。

直接点击表格中的编号编辑，离开输入框或按回车保存。右侧「类型序号」也能编辑，与其他行配置一起保存。

表格上方可搜索编号或类型名称、按字母前缀筛选分类、选择编号正序或倒序、仅显示勾选行。默认显示全部任务。编号采用自然排序，例如 A02 排在 A10 前面。拖动后切换为手动顺序；存在筛选时，隐藏行的位置保持不动。筛选时「生成当前 N 行」只提交当前可见行，「生成选中」只提交可见的勾选行。

把本地图片或图片文件夹拖到右侧「参考来源」的虚线框，一张图采用单图模式，多张图或文件夹采用素材池模式。拖入会替换当前行参考来源，不改提示词和其他参数；点击「保存本行」后生效。拖入无效文件会报错并保留原配置。文件夹与原有选择方式一致，读取直接包含的图片。

## 批量混剪

1. 每一行是一个段落，填入候选文案（每行一条），选择本段素材文件夹。可增加段落、调整段落顺序，取消勾选不参与的段落。文件夹包含子文件夹。
2. 默认按文案组合，每个段落取一条候选，按表格顺序拼接，再从本段文件夹匹配画面。如果本段只有一条固定文案，希望文件夹中的每个文件各出一版，可选择「固定一条文案，按文件逐个组合」。这种模式不会猜测多条文案与文件的对应关系。
3. 数量按所有启用段落动态计算。例如四段分别有 4、3、4、5 条候选，会得到 240 条；数字仅是示例，应用中没有固定的段数或组合数。每页预览 10 条，也可先处理前几条做效果检查。
4. 选择配音预设或已经绑定的语音连接，设置成片比例和字幕。可选 AI 素材识别；识别和配音会调用用户配置的服务。未启用 AI 识别时，使用已有描述、文件名和本段手选素材进行匹配。
5. 可选开头视频：「保留原声」会完整播放片头，再接正文旁白；「片头静音」由正文旁白覆盖。
6. 点击「开始混剪」。每个组合先合成完整旁白，再读取实际时长、匹配镜头并保存时间线草稿，不需要先渲染一遍 MP4。相同全文和声音设置复用已保存配音；已完成的相同组合复用原草稿及人工修改。
7. 草稿完成一条即出现一条。可停止后续组合，当前条完成后停止；已保存结果保留。遇到素材不足会显示具体原因，配音缓存保留。再次开始会跳过相同的已完成草稿。

## 时间线与剪映

打开任意草稿，画面、配音、音乐／音效、字幕分别显示。可拖动片段改变位置，添加或删除素材，在播放头分割片段，设置起点、时长、素材入点与音量，支持撤销和保存。移动配音不会自动移动画面或字幕，修改后请试听对应时间范围。

有服务时间戳时按时间戳分配段落；没有可用时间戳时按文字长度估算边界和字幕，并在草稿里提示检查。片头原声与正文旁白保持独立片段。

「导出编辑版」生成视频。也可以在草稿列表勾选多条，批量导出视频。

导出剪映前，先在剪映「设置 → 草稿位置」找到根目录，然后在时间线左侧选择这个文件夹，点击「导出剪映草稿」。每次导出新建一个独立作品文件夹，复制并校验所需素材，保留轨道、字幕、裁切与音量，不覆盖原作品，也不修改剪映现有索引。重新打开或刷新剪映草稿页后检查该作品。

草稿结构参考本机图书工具及 [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft)。剪映不同版本的兼容性需要在目标版本实际打开确认；文件生成与结构验证不代表剪映应用内验收。

## 数据与交付边界

原图片行、模型连接、加密凭据、生成记录和旧混剪配置保留。旧配置可在混剪页底部载入，新混剪工作配置自动保存。历史成片仍可进入时间线继续编辑。

本次本地验证使用隔离工作区及本机模拟语音服务，不调用付费接口。实际交付和清理结果记录在 `local-delivery.json`。
