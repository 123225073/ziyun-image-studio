# 0.5.0 文字素材绑定与目录配置

本版可以把同一条文案中的不同文字分别对应到素材子目录。完整组合先校对，通过后再生成整篇配音，以配音时间安排画面。图片任务中的参考来源与保存位置也可以分别设置。

## 文件选择与模型连接

文件选择器记住同类操作上次成功选择的目录，重启后仍可使用。图片、视频、音频、Excel、混剪素材和输出位置分别记忆；取消选择不会改变记录。原目录不存在时，回到可访问的上级目录。

在「全局设置 → 模型服务」添加或编辑连接时，可直接修改「配置名称」。点击「获取模型」只更新可选列表，不会把当前模型换成列表第一项；请自行选择或填写模型名称，再保存。名称用于辨认连接，不决定服务实际调用的模型。

## 为文字指定画面

1. 在「混剪成片 → 素材目录库」点击「导入素材大目录」，选择包含各类图片子目录的总目录。界面显示每个目录的名称和图片数量；各目录只使用本层图片，不把下级目录的内容混到一起。
2. 按段落添加候选文案。每个编号框是一条候选，框内换行属于同一条内容。组合数量按所有启用段落的实际候选数计算。
3. 在候选框内选中一段文字，选择它对应的素材子目录，点击「绑定选中文字」。也可点「选择整条」。同一条文案可标注多个不重叠的范围，分别对应不同目录。
4. 检查下方的高亮文字和目录名称。相同短句出现多次时，绑定的是实际选中的那一次。可逐项更换目录或删除标注；空目录不能用于绑定。

例如，一条文案的前半句介绍外观、后半句介绍使用场景，可以分别绑定「产品外观」和「使用场景」两个目录。生成时，每个文字范围从对应目录随机选一张图片。随机选图可能再次选中相同图片，不保证每次都不同。

未标注的正文使用本段默认素材；如果既未绑定目录，也没有默认素材，需补充后才能生成。修改候选文案后，旧选区会提示重新绑定，避免文字位置移动后配错画面。原图片不会因绑定而被修改或移动。

## 校对、改写与配音

在「AI 文案与素材校对」选择文字模型与处理范围，点击「开始 AI 校对」。先查看有问题的组合，可对单条或选中多条执行「重新搭配」或「轻度改写」，比较建议后再采纳。采纳只影响对应的完整组合，原候选文案保留。

轻度改写涉及已绑定文字时，会重新核对实际图片内容与新文案是否适配，并定位新的文字范围。程序会检查相关目录中的图片，复用内容未变的有效描述；需要识别图片时使用所配置的「混剪素材识别」视觉连接，再交由语言模型复核。目录中可被随机选中的图片都需要覆盖，不能只凭目录名称认定适配。图片识别与语义复核可能产生额外服务调用。

无法完成识别、图片与新文案不符，或无法确认新选区时，会标记「素材对应待确认」。打开「检查素材对应」，删除待确认标注，为当前文字重新选择目录。已复核的图片被替换或目录内容变化后，也需要重新确认。

采纳改写、重新搭配或实质调整素材对应后，必须重新校对。只有当前完整组合通过校对，且素材对应已处理，才能生成配音与草稿；未校对、有问题或校对失败时不会开始配音。AI 通过表示未发现明显问题，事实、承诺和最终画面仍需人工检查。

开始混剪后，每条完整组合合成一份整篇配音，再按配音时间安排各段及选中文字对应的画面。服务返回可用时间信息时优先使用；无法精确对齐时会提示估算，需要试听调整。配音、画面、音乐、字幕进入独立轨道，可继续编辑并导出视频或剪映草稿。已有整篇音频的文案如需改写，应先解除音频绑定，再为新文案配音。

## 参考图片与保存位置分别设置

右侧「参考来源」决定生成时使用哪些图片。「本行保存子目录」决定导出到哪里；两项可以分别调整，更换参考图片不会清除已指定的保存位置。

- 上传或拖入多个图片文件时，可以一起作为参考；每次共同上传最多 16 张。普通图片文件夹默认逐张轮流使用，可在「多张参考图使用方式」中调整。超过 16 张时不能切换为全部一起上传。
- 使用系统输出目录时，「本行保存子目录」填写相对名称，留空按类型名称创建。
- 点击「指定母图 / 子图目录」选择一个类型目录，自动定位其「子图」文件夹。已选择的目录本身叫「子图」时，不会再套一层。此操作只调整保存位置，不替换参考图片。
- 指定后的完整路径显示在「本行保存子目录」中。通过「更换保存位置」调整，或点击「使用系统输出目录」恢复普通保存方式，再保存本行。

开启自动导出时，生成成功后保存到该行位置；关闭时，点击下载或导出后保存。导出失败会保留已经生成的本地结果，修复目录后可重试导出，无须重新生图。

## 多母图文件夹与 Excel

图片任务的「文件夹导入」用于一次导入多个类型，例如：

```text
素材总目录/
  A01-产品外观/
    母图1.jpg
    母图2.jpg
    子图/
  B01-使用场景/
    场景一.jpg
    场景二.jpg
    子图/
```

每个类型目录建立一行任务。存在「母图、母图1、母图_2」等母图系列命名时，使用该系列；没有母图命名时，使用本层所有图片。每行最多 16 张，一起作为参考。已有「子图」内容不会成为参考。导入预览显示张数、文件名、保存路径和错误；确认仅创建任务，不自动反推或生图。

Excel 模板的「导出位置」填「原目录子图」，「参考素材路径」填单个类型目录，也采用上述规则。此模式的「保存子目录」留空，预览识别出完整子图路径后自动回填到应用中的「本行保存子目录」，导入后可继续分别调整参考和保存位置。

「导出位置」留空则继续使用系统输出目录，旧 12 列模板仍可导入。手工参考提示词优先；只有参考提示词为空且「自动反推」填写 X 时才执行一次反推，仍以本行第一张参考图为依据。多母图共同上传指图片生成，不表示反推会逐张调用。确认前可看到自动反推次数；导入不会自动生成图片。

## 验证与版本状态

本版功能已在 Windows 本地进行定向测试和隔离桌面交互验证，模型请求使用模拟服务。测试覆盖保存恢复、完整文案处理顺序、多母图共同上传、目录写回及失败重试，不代表真实付费模型的生成质量已验收。

Windows 安装包验收、Mac 构建和各平台发布状态，以对应 GitHub Release 的说明、附件及校验文件为准；源码更新不代表所有平台安装包已经交付。Mac 安装包未经 Apple 公证。剪映导出后仍需在目标剪映版本检查兼容性。
