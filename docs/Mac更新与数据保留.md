# Mac 更新与数据保留

同一台 Mac、同一个 macOS 用户账户中，更新时只需替换「应用程序」里的「子云影像工坊」。项目、任务记录和应用内保存的生成结果放在独立的数据文件夹中。

1. **先保存并退出。** 保存正在编辑的内容，等生成、下载、导出结束，按 ⌘Q 退出工坊。
2. **首次跨版本升级，先备份。** 在访达按 ⇧⌘G，粘贴 `~/Library/Application Support/子云影像工坊/` 后回车。按 ⌘↑ 回到上一级，将整个「子云影像工坊」文件夹复制到自己的备份位置。另存到其他目录或外置磁盘的素材、导出文件仍在原位置，备份时按需另存。
3. **选择对应的 DMG。** 点苹果菜单里的「关于本机」。显示 Apple M 系列芯片时选 `mac-arm64.dmg`，显示 Intel 处理器时选 `mac-x64.dmg`。[最新正式版](https://github.com/123225073/ziyun-image-studio/releases/latest)
4. **覆盖安装。** 打开 DMG，把「子云影像工坊」拖到「应用程序」，出现同名提示时选「替换」。推出 DMG，从「应用程序」打开工坊。Mac 安装包采用临时签名，未经 Apple 公证。
5. **检查原项目。** 点应用名旁的版本号，确认已更新。打开原项目、任意一条历史任务和一张旧结果图，核对模型连接和导出目录。密钥受当前用户的登录钥匙串保护，若系统询问，先核对是刚从正式发布页安装的工坊，再允许访问。若仍提示连接缺少密钥，可在「全局设置」中仅重新填写该连接的 API Key。项目、历史图片和输出目录可独立核对。使用外置磁盘上的素材时，先接回原磁盘。

以后可点应用名旁的版本号，选择「检查更新」和「打开 GitHub 发布页」，下载新版后重复覆盖安装。当前版本由用户手动下载安装。

**需要回退时**，先退出并另存更新后的数据，以保留升级以来的新工作。再从历史 Release 安装旧版，并恢复当时为该版本制作的数据备份。只有应用文件的替换无需搬迁数据，换电脑或换 macOS 账户时还涉及钥匙串和外部素材路径。
