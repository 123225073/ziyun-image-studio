# 0.5.1 混剪分步操作

混剪页面按制作顺序排列，每步标记用户操作或系统自动处理。顶部步骤导航和每步末尾的下一步入口只负责定位，不会提交 AI、配音或视频任务。

1. **文案与素材**：导入素材大目录，填写各段候选并绑定文字范围。没有绑定的文字可使用本段备用素材。整篇模式可填写全文或绑定已有配音。
2. **完整组合**：系统自动从每段取一条候选组成全文，无需点击拼接。选择本次处理范围；需要检查全文时展开「查看完整文案预览」。
3. **AI 校对**：选择校对连接，点击「开始 AI 校对」。有问题的组合可重新搭配或轻度改写，查看建议后采纳；处理待确认素材并重新校对，通过后继续。
4. **配音与片头**：设置音色、比例、字幕和可选片头。这一步只保存设置，不会自动合成声音。已有且与全文一致的音频可以复用。
5. **生成草稿**：点击「生成配音与时间线」，系统为每条全文合成完整配音、匹配画面并保存时间线。已有配音时按钮明确显示复用。此步骤准备可编辑草稿，最终视频在下一步导出。按钮不可用时，查看旁边的原因并点击相应定位入口处理。
6. **编辑与导出**：点击草稿的「打开时间线」编辑画面、配音、音乐与字幕。时间线中「导出编辑版」生成 MP4；选择剪映草稿位置后可「导出剪映草稿」。也可勾选多个已检查的草稿并批量导出视频。

自动处理进度按实际完成的组合更新。系统正在处理当前组合时，不会把预先显示的处理顺序当作已完成状态。旧配置与素材描述收在辅助设置中。

修改候选文案或素材绑定后需要重新校对。修改音色、画幅或片头属于制作参数设置，不会自行触发付费任务。模型相关验收使用本地模拟接口，不代表真实模型生成质量已验收。
