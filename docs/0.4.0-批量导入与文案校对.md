# 0.4.0 图片任务与混剪操作说明

## 图片任务

新增类型默认从 A01 开始，后续沿用列表最后一行的字母分类，例如最后一行是 B01，新增就是 B02。已存在的编号会跳过。手工编号和整行拖动分别控制分类编号与排列位置，拖动时其他配置、结果和历史记录都保持关联。

勾选任务后点击“删除选中”。筛选时只处理当前可见且勾选的任务，删除前显示具体列表。未结束或结果未知的生成任务需先处理完；已输出媒体不会随任务行删除。

## Excel 批量导入

在“图片素材”点击“Excel 批量导入”，下载模板。

1. 只填写“任务”工作表，一行一个任务。“说明”和“示例”表不导入。
2. “参考素材路径”可填图片文件或图片文件夹。支持本机绝对路径，以及相对于 Excel 所在文件夹的路径，例如 `素材/参考图.png`。文件夹读取直接包含的图片。Excel 中不必嵌入图片，也可以留空、导入后在应用里选择。
3. 参考提示词和用户要求可以在一个单元格中换行。已有手工参考提示词时始终保留，即使自动反推填了 X，也不会调用反推。
4. 只有参考提示词为空、自动反推填写 X 才会调用视觉服务。可在“反推要求”补充关注点；每行使用第一张参考图进行一次反推。未填写 X 就不调用。
5. 可选参数留空采用新建行默认值：生成数量 1、比例跟随原图、分辨率 1K、当前默认项目规范。编号自动续号。项目规范也可填现有规范名称或 ID；填“不使用模板”可取消规范。
6. 选择填写后的 Excel，预览编号、素材、默认值和反推数量。错误行会指出 Excel 行号，修正后重新选择。确认后仅新增任务，不覆盖现有行，不自动生成图片。
7. 自动反推失败时任务仍保留。修复模型连接或素材后点击重试；已手工补充的提示词和已成功结果不会重复反推。应用重启不会自动重新调用未完成的反推。

支持 .xlsx，单次最多 500 个任务、10 MiB。公式和超链接请先转为普通文字或数值。跨电脑使用时，相对路径便于将 Excel 与素材文件夹一起复制；Windows 盘符路径不能直接在 Mac 使用。

## 文案组合与校对

每个段落有若干个独立编号的候选文案输入框。一个框就是一条候选，长文字自动换行和手动回车都仍属于这一条。点击“新增文案”添加另一条；大量文案可“批量粘贴”，明确选择空行、竖线或逐行分隔，查看分割预览后再确认。

段落“使用”控制是否参与组合，段落“选择”用于批量删除。组合数量按所有启用段落的实际候选数动态计算，不固定段落数或示例数字。每段选择自己的素材文件夹。

组合完成后可先执行“AI 文案逻辑校对”。先选择文字模型连接与范围，校对结果分为通过、有问题、待复检 / 失败。点击按钮才调用所选服务。

- “重新搭配”：只从已有候选文案中重新选择，素材仍使用对应段落来源。
- “轻度改写”：尽量保留原句和数字，调整衔接或不合理表达。
- 单条或勾选后批量操作均可。生成建议不会直接替换；比较当前文案和建议，再点击“检查并采纳”。采纳只影响这一条完整组合，不覆盖原始候选。

采纳后可重新校对。修改了段落内容、顺序或素材来源后，会按新组合重新识别校对状态。已绑定整篇音频时，需解除配音绑定才能改文案，避免文字与声音不一致。AI 校对不能替代事实核查。

## 时间线与导出

点击开始混剪后，每条完整文案先合成完整配音，再按配音时间匹配素材，生成一条独立草稿。已完成的相同草稿可继续编辑。画面、配音、音乐和字幕分轨显示，可添加、拖动、删除、分割片段及调整入点、时长。

先保存草稿，再导出 MP4；也可选择剪映的草稿根目录，导出带独立素材的剪映草稿。在目标剪映中检查后再进行最终发布。
