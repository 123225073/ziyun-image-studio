# 0.5.2 Mac 密钥保存修复

旧版在保存 API 配置前使用同步接口检查系统加密能力。在部分 Mac 环境中，该检查返回不可用，界面只显示「系统安全存储不可用，未保存凭据」，用户无法区分本机密钥保存失败与中转平台请求失败。

本版改用 Electron 提供的异步安全存储接口，并继续使用 macOS 钥匙串和 Windows 系统加密。旧版已保存的加密密钥可继续读取；不会要求全部重新录入，也不会用明文文件替代系统安全存储。

## 朋友升级后如何操作

1. 正常退出旧版，将新版应用安装到「应用程序」，再打开。
2. 在「全局设置 → 模型服务」重新打开之前的配置；如果之前根本没有保存成功，就重新添加。
3. 填写服务地址、API Key 和模型，点击保存。如果系统弹出钥匙串访问提示，请由本人核对应用名称并处理授权。
4. 如仍无法保存，查看弹窗内的具体提示。名称、地址、模型和当前输入保留在弹窗内，可处理系统提示后重新尝试；完全退出应用后，未保存的密钥需重新输入。

系统真正拒绝钥匙串访问、钥匙串被锁或系统安全存储无法使用时，应用不能擅自越过系统权限。若重试仍失败，按提示正常退出再打开；不要删除钥匙串或工作空间数据。

本机保存密钥成功后，才继续通过「获取模型」检查平台连接。该检查使用所填写的地址和密钥，但模型列表可读取不代表所选模型的识图、图片生成或语音能力均可用。

## 验证范围

凭据验收使用隔离工作空间、测试密钥和本地模拟模型端点，检查旧同步能力返回不可用但新接口可用、旧密文兼容、保存失败后保留配置、重试及重启恢复。测试不会发送用户真实密钥，也不会调用真实付费模型。

Mac 包仍为临时签名，尚未取得 Apple Developer ID 正式签名和公证。系统仍可能要求本人授权钥匙串访问。本修复解决应用的旧接口误判和失败恢复，不能保证免除系统授权，朋友电脑上的最终结果仍需升级后确认。
